# Security policy

## Supported versions

The current 1.0.x release line receives security fixes. Earlier 0.x releases do not receive security fixes.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/calculatetech/synodrive-dolphin/security/advisories/new). Include the affected version, impact, and minimum reproduction steps. Remove private paths, account names, server names, and generated share links.

This project does not contain Synology software. For a vulnerability in Synology Drive Client, contact Synology directly.
